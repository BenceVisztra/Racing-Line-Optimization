# Racing Line Optimization
This repository contains matlab code meant to calculate lap times and draw optimal racing lines for simple tracks, with adjustable maximum acceleration and jerk values to respect vehicle dynamics.

As an example, the t-race track is included in the code:
https://t-raceglobal.com/

The following vehicle parameters are adjustable:
- lateral acceleration
- longitudinal forward acceleration
- longitudinal backward acceleration
- lateral jerk
- longitudinal jerk
- minimum turning radius
